## 这个博客是怎么来的

技术栈很朴素：

| 部分 | 用了什么 |
| --- | --- |
| 静态站点框架 | Hexo 8 |
| 主题 | Butterfly 5.7 |
| 托管 | GitHub Pages |
| 写作格式 | Markdown |

搭建过程中最折腾的不是 Hexo，而是**网络**：本机把 `github.com` 解析到了一个不可用的 IP（DNS 污染），命令行和 GitHub Desktop 都连不上，只有浏览器能开。最后的解法是给 git 指定可用 IP，再用 OAuth 设备码完成授权。

## 以后怎么写文章

三步：

```bash
cd ~/Documents/deepseek-harness/default-workspace/blog   # 进入博客目录
npx hexo new "文章标题"                                   # 1. 新建文章
#                                                        2. 用编辑器写 Markdown
./deploy.sh                                              # 3. 一键发布
```

文章文件会生成在 `source/_posts/` 目录下，用任何 Markdown 编辑器（VS Code、Typora、Obsidian 都行）打开就能写。

## Markdown 常用语法速查

**加粗**、*斜体*、`行内代码`、[链接](https://hexo.io)。

有序列表：

1. 第一步
2. 第二步
3. 第三步

无序列表：

- 苹果
- 香蕉
- 橘子

代码块（写语言名会有高亮）：

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("dawn"))
```

引用：

> 先让它跑起来，再让它跑得漂亮。

## 一个踩坑提醒

文章开头 `---` 包起来的部分叫 **front-matter**，用来填标题、日期、标签、分类。注意两点：

1. 冒号后面**要有一个空格**，`title: 你好` 是对的，`title:你好` 会报错
2. 标签写成列表形式：

```yaml
tags:
  - Hexo
  - 开始
```
