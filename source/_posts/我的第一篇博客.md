欢迎来到 **dawn的01纪元**！这是用 Hexo + Butterfly 主题搭建的第一篇文章。

## 写文章的方法

在博客目录下执行：

```bash
cd ~/Documents/deepseek-harness/default-workspace/blog
npx hexo new "文章标题"
```

文章会生成在 `source/_posts/` 目录，用 Markdown 写完内容后，执行一键发布：

```bash
./deploy.sh
```

大约 30~60 秒后，就能在 https://dawn0424.github.io/blog/ 看到新文章了。

## 这篇示例文章可以删掉

想删除的话，直接删掉 `source/_posts/我的第一篇博客.md`，再运行一次 `./deploy.sh` 即可。
